При неверном binding либо удалённом аккаунте token удаляется и возвращается 401. Старые записи отдельной D1b таблицы без binding мигрируются в транзакции SQLite и отзываются fail-closed, повторная миграция идемпотентна. `POST /admin/subpage/api/sessions/revoke` требует cookie + HTTPS Origin/Host + CSRF, доступен пользователю для своего аккаунта и owner для указанного администратора; viewer/editor не могут отзывать чужие сеансы. При SQLite отказе результат 503. React UI получает «Завершить все сеансы» и не имитирует успешный одиночный logout при неудаче запроса. Бот, `/compat/`, публичная подписка и релизный state не изменены
